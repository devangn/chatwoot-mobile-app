# Fix Sentry Source Map Upload

## Problem
Sentry upload fails with "No such file or directory" because bundle/sourcemap files aren't generated before upload.

## Solution Steps

### 1. Uncomment Sentry Configuration

Edit `android/sentry.properties` and uncomment:

```properties
defaults.org=let-them-connect
defaults.project=ltc
auth.token=YOUR_SENTRY_AUTH_TOKEN_HERE
```

### 2. Clean Build First

The bundle files need to be generated. Do a clean build:

```bash
cd android
./gradlew clean
./gradlew assembleRelease
```

### 3. If Still Failing - Check Bundle Generation

The bundle should be generated by the `createBundleReleaseJsAndAssets` task. If it's still failing, try:

```bash
# Build with more verbose output
./gradlew assembleRelease --info

# Or build the bundle task explicitly first
./gradlew :app:createBundleReleaseJsAndAssets
./gradlew assembleRelease
```

### 4. Alternative: Make Upload Non-Fatal (if files missing)

If you want the build to succeed even if source maps aren't uploaded, we can modify the gradle configuration to continue on error. But first try the clean build approach above.

## Why This Happens

The Sentry upload task runs as part of the build, but sometimes the bundle generation task hasn't completed yet. A clean build ensures all tasks run in the correct order.
